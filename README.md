## 📖 About

**Valentine** is an elegant, romantic web application crafted to deliver personalized Valentine's Day greetings, heartfelt messages, and memorable interactions.

Featuring smooth CSS animations, floating rose petals, interactive love letter reveals, and joyful confetti celebrations, it offers a charming digital card experience for someone special.

---

## ✨ Features

- 💌 **Interactive Love Envelope**: Click-to-open digital letter animation with smooth unfolding effects.
- 🌹 **Falling Petals & Hearts**: Fluid particle animation creating an enchanting romantic atmosphere.
- 💖 **Playful Questions & Confetti**: Interactive choice buttons ("Yes" / "Definitely Yes!") triggering celebratory confetti bursts.
- 📱 **Fully Responsive**: Beautiful layout tailored for mobile phones, tablets, and desktop browsers.
- ⚡ **Lightweight & Fast**: Pure client-side static web application with instantaneous loading.

---

## 🛠️ Tech Stack

- **Markup**: [HTML5](https://developer.mozilla.org/en-US/docs/Web/HTML)
- **Styling**: [CSS3](https://developer.mozilla.org/en-US/docs/Web/CSS) (Keyframe Animations, Flexbox, Gradients)
- **Scripting**: Vanilla [JavaScript ES6+](https://developer.mozilla.org/en-US/docs/Web/JavaScript) & Canvas Confetti

## 🚀 Quick Start

1. **Clone repository:**
   ```bash
   git clone https://github.com/kecrwn/Valentine.git
   cd Valentine
   ```

2. **Open in browser:**
   Open `index.html` directly in your favorite browser, or start a lightweight server:
   ```bash
   python3 -m http.server 8080
   ```

3. Navigate to `http://localhost:8080`.
